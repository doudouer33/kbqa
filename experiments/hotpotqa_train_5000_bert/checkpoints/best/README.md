# Selected BERT checkpoint

The best checkpoint is epoch 2, selected solely by Validation Soft CE. `config.json` and `selection.json` are versioned here. The approximately 418 MiB `pytorch_model.bin` and tokenizer files remain on the experiment host; the weight SHA256 is recorded in `../../reports/final_validation.json`.

This GitHub directory provides checkpoint metadata, not downloadable trained weights. Full training/evaluation code and aggregate reports are available in the experiment directory.
